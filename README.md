# SOS WiFi B2B Website

OFFICIAL-SENSITIVE

This ZIP contains a complete Vercel-ready React/Vite project for the SOS WiFi B2B website.

## Upload to GitHub

1. Extract this ZIP file.
2. Open your GitHub repository named `B2B`.
3. Click **uploading an existing file**.
4. Upload the extracted project contents, not the ZIP itself:
   - package.json
   - vite.config.js
   - index.html
   - README.md
   - src/
   - public/
5. Commit the files to the `main` branch.

## Deploy to Vercel

1. Go to Vercel.
2. Select **Add New > Project**.
3. Import the GitHub repository `B2B`.
4. Keep the default Vite settings.
5. Click **Deploy**.
6. Add `business.soswifi.uk` in Project Settings > Domains.

## Note

The enquiry form is currently visual/front-end only. To receive enquiry emails you will need to connect it to a form service or a Vercel serverless function.
